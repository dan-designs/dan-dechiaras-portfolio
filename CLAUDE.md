# dandesigns.io

Dan Dechiara's portfolio site. Live at https://www.dandesigns.io

## Stack

Vite + React 19 + TypeScript + Tailwind 4. Deployed on Vercel from `main`.
All page content currently lives in `src/App.tsx`.

## Hard rules

- **Never regenerate `src/App.tsx` wholesale.** Make surgical, targeted edits.
  If a request seems to call for a rewrite, stop and ask first.
- **Never modify accessibility code** without explicit instruction: the
  A11yDashboard, A11yTooltip, A11yExplainerCard, XRAY_DATA, LighthouseGauge,
  LighthouseFooter components, any `aria-*` attribute, any `sr-only` class,
  or semantic markup. This site demonstrates accessibility practice; it is a
  credential, not decoration.
- **Never modify the i18n / LANGUAGES system.**
- **No em dashes anywhere in copy.** Use commas, colons, semicolons, or
  parentheses.
- Preserve existing code style: quote style, indentation, JSX conventions.
- Always run `npm run build` before committing.
- Work on a branch, never commit directly to `main`. Show the diff before
  committing.
